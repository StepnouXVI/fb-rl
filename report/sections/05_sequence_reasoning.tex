\section{High-Level Sequence Reasoning \& Waypoint Translators}

While amortized $O(1)$ distillation provides remarkable speed, certain hairpin turns in AntMaze benefit from explicitly conditioning on the multi-hop topological sequence $\mathcal{P} = [w_1, w_2, \dots, w_K, g]$. We designed two distinct translators to replace the default stochastic \texttt{high\_actor}.

\subsection{Single Waypoint Gated Translator (\texttt{SingleWPPlanner})}
The Single Waypoint Translator maps the current state $s_t$ and the immediate lookahead waypoint $B(w_1)$ directly to the low-level intention $z_{\text{cmd}}$:
\begin{align}
    h_s &= \text{MLP}_s(s_t), \quad h_w = \text{MLP}_w(B(w_1)) \\
    \gamma &= \sigma(\text{Linear}([h_s, h_w])) \\
    h_{\text{fused}} &= \gamma \odot h_w + (1 - \gamma) \odot h_s \\
    z_{\text{cmd}} &= \text{ProjectSphere}(\text{ResNetBlocks}(h_{\text{fused}}))
\end{align}

\subsection{Enhanced Sequence-Aware Attention Transformer (\texttt{EnhancedSequencePlanner})}
Standard transformers trained over multi-hop sequences suffer from \textit{wall-leakage}: if a waypoint $w_4$ located in an adjacent corridor is Euclidean-close to $s_t$, unconstrained cross-attention assigns high weight to $w_4$, pulling the robot into the dividing wall. 

To overcome this fundamental challenge, our \texttt{FlaxEnhancedSequenceWaypointAttentionTranslator} introduces four key mathematical mechanisms:

\subsubsection{1. ALiBi Distance-Decay Cross-Attention Bias}
Inspired by ALiBi \cite{press2021train}, we inject an explicit geometric distance penalty into the cross-attention logits before the Softmax operation:
\begin{equation}
    \text{Attn}(Q_s, K_w) = \text{Softmax}\left(\frac{Q_s K_w^\top}{\sqrt{d_{\text{head}}}} - \lambda_{\text{decay}} \cdot m_h \cdot \min(k, W)\right)
\end{equation}
where $k \in \{0, 1, \dots, K-1\}$ is the index along the trajectory, $m_h = 2^{-4h/(H-1)}$ are head-specific geometric decay rates across heads $h \in \{0, \dots, H-1\}$, and $\lambda_{\text{decay}} = 0.4$. This guarantees that 75--80\% of the attention weight concentrates strictly on the immediate corridor, while the tail provides global orientational anchoring.

\subsubsection{2. Local-Global Windowing and Terminal Anchoring}
The attention mask $\mathcal{M}$ restricts keys to the active local window $k < W$ ($W=6$) plus the designated global terminal goal token $[B(g_{\text{final}})]$, mathematically blocking attention leakage to distant intermediate turns.

\subsubsection{3. Curvature and Turn Encodings}
For every consecutive triplet of waypoints $(w_{k-1}, w_k, w_{k+1})$, we compute the cosine turn angle:
\begin{equation}
    \cos \theta_k = \frac{(w_k - w_{k-1}) \cdot (w_{k+1} - w_k)}{\|w_k - w_{k-1}\|_2 \|w_{k+1} - w_k\|_2 + 10^{-6}} \in [-1, 1]
\end{equation}
This scalar is projected via a dedicated linear layer $E_{\text{curv}} = \text{Linear}(\cos \theta_k)$ and summed with the waypoint token representations $w_{\text{emb}} = w_{\text{proj}} + P_k + E_{\text{curv}}$, providing explicit inductive bias for sharp $90^\circ$ turns.

\subsubsection{4. Multi-Stage Trajectory Sampling and Auxiliary Local Loss}
During offline dataset generation (60,000 pairs), trajectory progress offsets $t \in [0, \text{len}(\mathcal{P})-1]$ are sampled uniformly, ensuring the transformer trains equally on long trajectories ($K=16$), mid-path sequences ($K=6$), and terminal single-step regimes ($K=1$). Furthermore, an auxiliary local step loss anchors predictions:
\begin{equation}
    \mathcal{L}_{\text{total}} = \mathcal{L}(\theta) + \lambda_{\text{aux}} \|\hat{z}_{\text{seq}} - z^*_{\text{single\_wp}}\|_2^2 \quad (\lambda_{\text{aux}} = 0.2)
\end{equation}
