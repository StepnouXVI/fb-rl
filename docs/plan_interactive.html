Zero-Shot RL 3 Git Ветки 9 Субагентов Math Auditor & Fable Judge
💡
Постановка задачи: Замороженные FB-модели выучили меру преемника (Successor Measure) $M(s, z)$. Одноинтенциональный бейзлайн выбирает один вектор $z$ за раз и застревает в лабиринтах на длинных горизонтах. Наша цель — построить планировщик цепочки подцелей $(w_1, w_2, \dots, w_K)$, строго без тяжелых генеративных моделей мира (World Models / Diffusers).

📐 DRY Архитектура с /ponytail

Все общие компоненты вынесены в модуль fb_core/, исключая дублирование логики между ветками:

  • fb_core/base_planner.py — абстрактный базовый класс с единым контрактом get_next_intention(obs, goal).
  • fb_core/fb_model_wrapper.py — загрузка и инференс замороженных весов FB ($F, B, \pi_l$).
  • fb_core/dataset_sampler.py — векторизованная выборка и Farthest Point Sampling (FPS).
  • fb_core/evaluator.py — универсальный раннер оценки на 5 сидах для antmaze-medium-navigate-v0.
  • fb_core/math_utils.py — численно стабильные функции ($\epsilon$-clipping, log-dot, нормализация).

🌿 Стратегия Git-веток

Каждый метод изолирован в своей ветке, но использует единое ядро:

  • main — ядро fb_core/, бейзлайн, тесты и сводный бенчмарк.
  • idea-1-recursive-bisection — Рекурсивный бинарный поиск подцелей (Divide & Conquer).
  • idea-2-buffer-graph-dijkstra — Топологический граф по датасету + Дейкстра в FB-метрике.
  • idea-3-distilled-latent-mlp — Дистилляция графа в легковесную MLP $\pi^h_\theta(s, B(g)) \to z$.

Математический фундамент Successor Measures:
Мера преемника $M^{\pi_z}_s(s')$ определяет дисконтированную плотность будущих посещений: $\frac{dM^{\pi_z}_s}{d\rho}(s') \approx F(s, z)^\top B(s')$. Скалярное произведение $F(s, B(w))^\top B(w)$ пропорционально вероятности агента достичь подцели $w$ из состояния $s$.

1. Рекурсивное деление (Bisection)

Без дообучения

Принцип «Разделяй и властвуй». Нахождение оптимальной медианной подцели $w^*$ из буфера с рекурсивным спуском.

$$w^* = \arg\max_{w \in \mathcal{V}} \left[ \log(F(s, B(w))^\top B(w)) + \log(F(w, B(g))^\top B(g)) \right]$$

Плюсы: Изолирует ошибку внутри подотрезков, не требует построения графа $O(N^2)$.
Контроль: Остановка рекурсии при $F(s, B(w^*))^\top B(w^*) > \tau_{\text{reach}}$ или глубине $\ge 3$.

2. Топологический граф (Dijkstra)

Без дообучения

Построение ориентированного графа $G=(V,E)$ по $N \approx 1000$ узлам датасета, отобранным через FPS.

$$c(s_i, s_j) = -\log\left(\max(F(s_i, B(s_j))^\top B(s_j), \epsilon)\right)$$

Плюсы: Глобальный оптимум обхода стен и лабиринтов, гарантированное отсутствие застреваний.
Исполнение: Поиск кратчайшего пути Дейкстрой $s \rightsquigarrow g$ и динамическое переключение по окрестности.

3. Дистиллированная MLP $\pi^h_\theta$

Сверхлегкое обучение

Дистилляция оптимальных путей графа в 3-слойную MLP для мгновенного инференса $O(1)$ без графового поиска в рантайме.

$$\mathcal{L}(\theta) = \mathbb{E} \left[ \|\pi^h_\theta(s, B(g)) - B(w_1^*)\|_2^2 + \lambda (1 - \cos(\hat{z}, z^*)) \right]$$

Плюсы: Инференс за 0.2 мс на шаг, идеальное соблюдение ограничений ТЗ (нет тяжелых генеративных моделей).
Обоснование: Устраняет квадратичную сложность графового поиска на инференсе.

🛡️ Математический чеклист для Субагента-Аудитора (Math Auditor)

Свойство / Теорема Математическая формулировка Проверка в коде
Неотрицательность меры $F(s, z)^\top B(s') \ge 0$ почти всюду safe_log_dot(F, B, eps=1e-6) с защитой от $\le 0$
Квази-метрика расстояния $d(s_i, s_j) = -\log(F(s_i, B(s_j))^\top B(s_j)) \ge 0$ $d(s, s) \approx 0$, $d(s_i, s_j) \le d(s_i, s_k) + d(s_k, s_j) + \delta$
Нормировка латентов $\|z\|_2 = \sqrt{d_{\text{latent}}}$ z / norm(z) * sqrt(dim) перед подачей в $F$ и $\pi_l$
Аддитивность путей $\log M(s \to g) \approx \log M(s \to w) + \log M(w \to g)$ Тест треугольника в test_math_properties.py
