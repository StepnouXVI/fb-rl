# Глубокое погружение в Forward-Backward (FB) Представления и Планирование Интенций в Zero-Shot RL

## 1. Введение и Постановка Задачи Zero-Shot RL

Традиционное обучение с подкреплением (Reinforcement Learning, RL) ориентировано на оптимизацию политики для одной фиксированной функции награды $r(s, a)$. При изменении задачи (награды) стандартный RL требует полного переобучения. 

В **Zero-Shot Goal-Conditioned RL (GCRL)** ставится иная задача:
1. **Этап оффлайн-обучения (Unsupervised / Reward-Free Phase):** Агент имеет доступ только к фиксированному оффлайн-датасету траекторий $\mathcal{D} = \{(s_t, a_t, s_{t+1})\}_{t=1}^N$, собранному некоторой целевой или исследовательской политикой без явной функции награды.
2. **Этап тестирования (Zero-Shot Test Phase):** Агенту предъявляется новая задача, заданная произвольной функцией награды $r(s, a)$ (или целевым состоянием $g$). Агент должен мгновенно (zero-shot, без дополнительного взаимодействия со средой и без дообучения нейросетей) исполнить политику, близкую к оптимальной.

## 2. Теоретические Основы: От Successor Features к Successor Measures

### 2.1. Successor Representation (SR) и Successor Features (SF)
Идея предсказания будущего посещения состояний восходит к **Successor Representation (Dayan, 1993)** для дискретных сред:
$$M^\pi(s, s') = \mathbb{E}_\pi \left[ \sum_{t=0}^\infty \gamma^t \mathbb{I}(s_t = s') \middle| s_0 = s \right]$$

Для непрерывных пространств признаков $\phi(s, a) \in \mathbb{R}^d$ **Successor Features (Barreto et al., 2017)** определяют ожидаемые будущие накопленные фичи при следовании политике $\pi$:
$$\psi^\pi(s, a) = \mathbb{E}_\pi \left[ \sum_{t=0}^\infty \gamma^t \phi(s_t, a_t) \middle| s_0 = s, a_0 = a \right]$$

Если награда линейно раскладывается по фичам: $r(s, a) = \phi(s, a)^\top w$, то функция ценности $Q^\pi(s, a)$ вычисляется мгновенно по скалярному произведению:
$$Q^\pi(s, a) = \psi^\pi(s, a)^\top w$$

Однако SF требуют **заранее заданного или выученного базиса фичей $\phi(s, a)$**, ограничивающего класс поддерживаемых наград.

## 3. Forward-Backward (FB) Представления (Touati & Ollivier, 2021)

Forward-Backward representations (FB) обобщают Successor Features на непрерывные пространства без фиксированного базиса признаков $\phi(s, a)$.

### 3.1. Successor Measure (Плотность Занятости)
Определим **Successor Measure** $M^\pi(s, a, \cdot)$ как мерную плотность будущих посещений состояний под действием политики $\pi$:
$$M^\pi(s, a, A) = \sum_{t=0}^\infty \gamma^t P^\pi(s_t \in A \mid s_0 = s, a_0 = a)$$

В непрерывном пространстве $M^\pi(s, a, s')$ удовлетворяет уравнению Беллмана:
$$M^\pi(s, a, s') = p_0(s' \mid s, a) + \gamma \int_{\mathcal{S}} \int_{\mathcal{A}} p(s'' \mid s, a) \pi(a'' \mid s'') M^\pi(s'', a'', s') \, ds'' \, da''$$

### 3.2. Низкоранговое Разложение в Гильбертовом Пространстве
Ключевая математическая идея FB состоит в аппроксимации $M(s, a, s')$ факторизацией ранга $d \ll \dim(\mathcal{S})$:
$$M^z(s, a, s') \approx F(s, a)^\top B(s')$$
где:
- $F: \mathcal{S} \times \mathcal{A} \to \mathbb{R}^d$ — **Forward representation** (прямое представление, кодирующее текущую позицию и действие);
- $B: \mathcal{S} \to \mathbb{R}^d$ — **Backward representation** (обратное представление, кодирующее будущие целевые состояния);
- $z \in \mathcal{S}^{d-1} \subset \mathbb{R}^d$ — векторы латентных интенций (параметризующих семейство политик $\pi_z$).

### 3.3. Вычисление Q-функции и Политики
Для любой задачи с функцией награды $r(s)$, проекция этой награды на латентный базис дает вектор $z_r \in \mathbb{R}^d$:
$$z_r = \mathbb{E}_{s \sim \mathcal{D}} [r(s) B(s)]$$

Тогда Q-функция политики $\pi_z$ выражается скалярным произведением:
$$Q^z(s, a) = F(s, a)^\top z$$

**Политика нижнего уровня $\pi_l(a \mid s, z)$** выбирает действия, максимизирующие Q-ценность:
$$\pi_l(a \mid s, z) = \arg\max_a F(s, a)^\top z$$

### 3.4. Обучение FB-модели (Loss-функции)
Для обучения $F_\theta(s, a)$ и $B_\phi(s')$ используются TD-ошибки с условием ортонормированности эмбеддингов:
1. **TD Loss (Уравнение Беллмана на FB):**
   $$\mathcal{L}_{\text{FB}}(\theta, \phi) = \mathbb{E}_{(s, a, s') \sim \mathcal{D}, z \sim \mathcal{S}^{d-1}} \left[ \left( F_\theta(s, a)^\top z - \left( r(s, a, z) + \gamma F_\theta(s', \pi_l(s', z))^\top z \right) \right)^2 \right]$$
   где подменяемая награда равна $r(s, a, z) = B_\phi(s')^\top z$.

2. **Ограничение ортонормированности (Covariance Regularization):**
   $$\mathbb{E}_{s \sim \mathcal{D}} [B(s) B(s)^\top] = I_d$$

## 4. Иерархический Zero-Shot RL и Переключение Интенций (Stojanovic & Proutiere, 2026)

В иерархическом подходе (**FB $\pi$-Switch / Single-Intention Baseline**) архитектура состоит из двух уровней:
- **Low-level policy $\pi_l(a \mid s, z)$:** Замороженная низкоуровневая политика, исполняющая заданную латентную интенцию $z \in \mathbb{R}^d$.
- **High-level controller $\pi_{\text{high}}(z \mid s, g)$:** Контроллер верхнего уровня, который по текущему состоянию $s$ и глобальной цели $g$ выбирает вектор интенции $z$.

### 4.1. Механизм Базового High-Level Контроллера
Базовый одноинтенциональный контроллер строит вектор интенции за один шаг:
$$z^* = \arg\max_{z \in \mathcal{S}^{d-1}} \left( F(s, \pi_l(s, z))^\top z - \lambda \| B(s) + z - B(g) \|^2 \right)$$
или в упрощенном виде направления в пространстве $B$:
$$z \propto B(g) - B(s)$$

### 4.2. Ограничения Одноинтенционального Подхода (Single-Intention Bottleneck)
В сложных пространственных средах (например, лабиринт `antmaze-medium-navigate-v0`):
1. **Прямой вектор $z \propto B(g) - B(s)$ указывает на глобальную цель сквозь стены.**
2. Низкоуровневая политика $\pi_l(a \mid s, z)$, пытаясь двигаться напрямую в направлении $z$, упирается в геометрические препятствия и тупики лабиринта.
3. Одноинтенциональный контроллер не способен спланировать промежуточную последовательность поворотов за стенами.

## 5. Мульти-Субгольное Планирование Интенций (Multi-Subgoal Intent Planning)

Чтобы побить single-intention бейзлайн без тяжелых генеративных моделей мира (Diffuser, Trajectory Transformer), предлагается использовать **Графовый Поиск в Латентном FB-Пространстве**.

### 5.1. Построение Латентного Графа Состояний
Поскольку $B(s)$ уже кодирует геометрическую и динамическую близость состояний среды:
1. Выбираем из оффлайн-датасета $N$ ключевых опорных состояний $V = \{s_1, s_2, \dots, s_N\}$ (например, через k-means по $B(s_i)$ или случайное подмножество).
2. Вычисляем $B$-эмбеддинги для всех опорных вершин: $v_i = B(s_i) \in \mathbb{R}^d$.
3. Строим sparse k-NN граф $G = (V, E)$. Вес ребра между близкими состояниями $s_i$ и $s_j$:
   $$w(i, j) = \| B(s_i) - B(s_j) \|_2^2 \quad \text{или} \quad d_{\text{FB}}(s_i, s_j) = - \log \sigma(F(s_i, a_i)^\top B(s_j))$$

### 5.2. Алгоритм Мульти-Субгольного Планирования
```
Вход: Текущее состояние s_0, Целевое состояние g, Граф G=(V, E), FB-модель (F, B, \pi_l)

1. Проекция на граф:
   i_start = argmin_i || B(s_0) - B(s_i) ||
   i_goal  = argmin_i || B(g)   - B(s_i) ||

2. Графовый поиск (A* / Dijkstra):
   Найти кратчайший путь вершин в графе G:
   P = (s_{g1}, s_{g2}, ..., s_{gK}),  где s_{gK} = g

3. Генерация последовательности интенций:
   Для каждого промежуточного субгола s_{gk}:
   z_k = Normalize( B(s_{gk}) - B(s_{gk-1}) )

4. Исполнение:
   For k = 1 to K:
       For step = 1 to Horizon H:
           a_t = \pi_l(a | s_t, z_k)
           Выполнить действие a_t в среде, получить s_{t+1}
           If || B(s_{t+1}) - B(s_{gk}) || < threshold:
               Break (переход к следующей интенции z_{k+1})
```

## 6. Бенчмарк OGBench и Среда AntMaze

### 6.1. Характеристики Среды `antmaze-medium-navigate-v0`
- **Агент:** 8-степенной робот Ant (муравей со сложной физикой Mujoco).
- **Пространство состояний:** $\mathcal{S} \subset \mathbb{R}^{29}$ (координаты $x, y$, углы суставов, линейные и угловые скорости).
- **Пространство действий:** $\mathcal{A} \subset [-1, 1]^8$ (крутящие моменты в суставах).
- **Среда:** Средний лабиринт с коридорами, развилками и тупиками.
- **Оффлайн-датасет:** 1,000,000 переходов, собранных исследовательской политикой без наград.
