## 1. Mathematical Foundations & Rigorous Derivations

### 1.1 Successor Measures & Low-Rank FB Decomposition
The discounted state occupancy measure (successor measure) for policy $\pi$ is defined as:
$$M^\pi_s(s') = (1 - \gamma) \sum_{t=0}^\infty \gamma^t \mathbb{P}(s_t = s' \mid s_0 = s, \pi)$$

In the Forward-Backward (FB) representation framework (Touati & Ollivier 2021, Stojanovic & Proutiere 2026), $M^\pi_s(s')$ is factorized via low-rank embeddings $F: \mathcal{S} \times \mathcal{Z} \to \mathbb{R}^d$ and $B: \mathcal{S} \to \mathbb{R}^d$:
$$\frac{dM^{\pi_z}_s}{d\rho}(s') \approx F(s, z)^\top B(s')$$
where $\rho$ is the offline data distribution, $z \in \mathcal{Z}$ is the latent intention vector with $\|z\|_2 = \sqrt{d}$, and $F(s, z)$ predicts expected future occupancy under policy $\pi_z$.

### 1.2 The Single-Intention Baseline Bottleneck
Given a goal state $g$, the zero-shot task reward is $r_g(s) = \mathbf{1}_{\{s = g\}} / \rho(g)$. The value function simplifies to:
$$V^{\pi_z}(s; g) = F(s, z)^\top B(g)$$
The baseline high-level controller chooses a single intention $\hat{z} = \arg\max_z F(s, z)^\top B(g) \approx B(g)$. In complex mazes with U-turns, walls, and narrow corridors, $F(s, B(g))^\top B(g) \approx 0$ because direct transition under one stationary low-level policy $\pi_l(a \mid s, B(g))$ is unachievable without obstacle negotiation, causing agent stall or wall collisions.

### 1.3 Branch 1: Recursive Bisection (Divide & Conquer)
Instead of predicting one $z$, we decompose the path from $s$ to $g$ recursively.
Under the Markov property and geometric discounted composition:
$$\mathbb{P}(s \rightsquigarrow g) \approx \max_{w \in \mathcal{D}} \mathbb{P}(s \rightsquigarrow w) \cdot \mathbb{P}(w \rightsquigarrow g)$$
In log-density space over successor measures:
$$w^* = \arg\max_{w \in \mathcal{V}} \left[ \log \max\left(F(s, B(w))^\top B(w), \epsilon\right) + \log \max\left(F(w, B(g))^\top B(g), \epsilon\right) \right]$$
If reachability $F(s, B(w^*))^\top B(w^*) < \tau_{\text{reach}}$, bisection recurses on $[s, w^*]$ up to maximum recursion depth $D_{\max} = 3$, producing a dynamic binary tree of intentions.

### 1.4 Branch 2: Topological Graph Search on Replay Buffer
We construct a directed topological graph $G = (V, E)$ from a landmark subset $V \subset \mathcal{D}$ ($|V| = N \approx 1000$) selected via Farthest Point Sampling (FPS) in backward embedding space $B(s)$.
The directed edge cost $c(s_i, s_j)$ is defined as the negative log-successor reachability:
$$c(s_i, s_j) = \begin{cases} 
-\log\left(\frac{F(s_i, B(s_j))^\top B(s_j)}{\|F(s_i, B(s_j))\|_2 \cdot \|B(s_j)\|_2} + \epsilon\right), & \text{if } F(s_i, B(s_j))^\top B(s_j) > \delta_{\text{cutoff}} \\
\infty, & \text{otherwise}
\end{cases}$$
At inference time:
1. Embed start $s$ and goal $g$ into $G$.
2. Compute shortest path $s \to w_1^* \to w_2^* \to \dots \to w_K^* \to g$ via Dijkstra / A*.
3. High-level controller feeds $z_{k} = B(w_k^*)$ into $\pi_l(a \mid s, z_k)$, switching to $w_{k+1}^*$ when $\|s - w_k^*\|_2 < \epsilon_{\text{switch}}$ or $F(s, B(w_k^*))^\top B(w_k^*) > \tau_{\text{switch}}$.

### 1.5 Branch 3: Distilled Latent Multi-Subgoal Controller
To eliminate graph search latency at test time ($O(V^2 + V \log V)$), we train a lightweight 3-layer MLP $\pi^h_\theta: \mathcal{S} \times \mathcal{Z} \to \mathcal{Z}$ on offline optimal path pairs $(s, g) \mapsto z_{w_1^*}$ generated by Branch 2:
$$\mathcal{L}(\theta) = \mathbb{E}_{(s, g, w_1^*) \sim \mathcal{D}_{\text{paths}}} \left[ \|\pi^h_\theta(s, B(g)) - B(w_1^*)\|_2^2 + \lambda_{\text{cos}} \left(1 - \frac{\pi^h_\theta(s, B(g))^\top B(w_1^*)}{\|\pi^h_\theta\|_2 \|B(w_1^*)\|_2}\right) \right]$$
Provides $O(1)$ fast single-pass inference during environment step while retaining multi-subgoal path knowledge.

## 2. DRY & Ponytail Architecture: Unified Code Hierarchy

To avoid code duplication across branches, all shared mechanics are isolated in `fb_core/`:

```
fb-rl/
├── fb_core/
│   ├── __init__.py
│   ├── base_planner.py         # Abstract Base Class BaseHierarchicalPlanner
│   ├── fb_model_wrapper.py     # Frozen FB/policy loader (JAX & PyTorch bridge)
│   ├── dataset_sampler.py      # Replay buffer sampler & FPS landmark selector
│   ├── evaluator.py            # Multi-seed environment rollout harness
│   ├── metrics_collector.py    # Metric aggregation, bootstrap CI, export CSV/JSON
│   ├── math_utils.py           # Safe log-dot operations, latent normalizations
│   └── visualizer.py           # 2D maze rollout trajectories & publication plots
├── planners/
│   ├── __init__.py
│   ├── baseline_planner.py     # Single-intention baseline
│   ├── recursive_bisection.py  # Branch 1 planner
│   ├── buffer_graph.py         # Branch 2 planner
│   └── distilled_mlp.py        # Branch 3 planner
├── tests/
│   ├── test_math_properties.py # Mathematical verification suite (Math Auditor)
│   ├── test_fb_model.py        # Checkpoint loading and forward/backward sanity
│   ├── test_planners.py        # Unit tests for all 3 planners + baseline
│   └── test_evaluator.py       # Rollout & metrics pipeline test
├── scripts/
│   ├── run_benchmark.py        # Single unified entrypoint to benchmark any/all planners
│   ├── generate_plots.py       # Generates PGFPlots data and PNG/PDF figures
│   └── export_report_data.py   # Synchronizes CSV metrics directly into LaTeX tables
└── report/
    ├── main.tex                # Formal LaTeX paper with updated empirical results
    ├── references.bib          # Bibliography
    └── figures/                # Auto-generated plots
```
